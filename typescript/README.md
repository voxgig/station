# station — TypeScript

The TypeScript port of [station](../README.md): one control surface for
outbound integrations.

```sh
npm test                      # conformance + integration suites
```

This port is **canonical**. `src/Station.ts` and its siblings define
station's behaviour; every other port is a translation of them, and a
change belongs here first.

Secrets are brokered through `@voxgig/sekreto`; the config grammar
validates through [voxgig/struct](https://github.com/voxgig/struct).
Those are the only two runtime dependencies a station library takes
(design §10).

## One entry

`package.json` `exports` names a single entry, `dist/src/index.js`.

There used to be two. A `browser` condition selected
`dist/src/index.browser.js` — the same surface **minus** the file-loading
half, so that no `node:` builtin was reachable from it — and three pieces
of machinery existed to keep that true: `profilecore.ts` held the pure
half of profile handling so the browser entry could reach it without
`node:fs`; `Station.ts` took `loadConfig`/`configScope` through a
`ConfigFileIO` seam that only the node entry registered; and
`test/browser.test.ts` walked the compiled `dist` graph asserting no
`node:` builtin appeared.

**Station is server-side only**, so all of it is gone: the second entry,
the condition, the seam, the split and the graph-walk test.
`profilecore.ts` is merged back into `profile.ts`, and `Station.ts`
imports `loadConfig` and `configScope` directly. Every import of
`./profile` is unchanged — that path always re-exported the pure half.

`setConfigFileIO` and its `ConfigFileIO` type were exported from this
package and are removed with the seam. Nothing in this repository or any
other voxgig port used them; the seam existed for the browser entry and
for nothing else.

## Layout

| | |
|---|---|
| `src/Station.ts` | the core: open/connect/adopt/options, sdk/create/check/warm, registry, transport middleware, the ref grammar |
| `src/index.ts` | the entry: the public surface |
| `src/adapter.ts` | `featureBinding` (the one binding entry) + the carried adapter |
| `src/shape.ts` | `normalizeConfig`/`validateConfig`: the §4 grammar, the §4.4 workarounds, the §5.2 credential scans |
| `src/config-shape.ts` | a verbatim mirror of [`spec/config-shape.json`](../spec/config-shape.json) — generated by `make sync-shape`, never edited by hand |
| `src/feature.ts` | the §8 three-level merge, order resolver, and descriptor-derived checker |
| `src/factory.ts` | the process-global factory table (`provide`, §6.2) |
| `src/loader.ts` | `loadSync`/`loadAsync`: CommonJS require + guarded dynamic import (§6.3) |
| `src/descriptor.ts` | descriptor v1 normalizer + canonical serializer |
| `src/secrets.ts` | the sekreto-backed broker + the placeholder |
| `src/profile.ts` | profile selection, the ref grammar, the §3.3 merge, `station.json` lookup and config scope |
| `src/events.ts` | the bounded event ring + tap |
| `src/error.ts` | the error-code catalog |
| `src/types.ts` | shared types; the descriptor and event shapes are pinned by the corpus, so evolve them additively |
| `src/omnihome.ts` | locates the sibling voxgig/omni checkout (test plumbing — it is not shipped) |

## Testing

The conformance suite runs [`spec/station.json`](../spec/station.json) —
the same file every port runs — through the TypeScript
[voxgig/omni](https://github.com/voxgig/omni) runner. Set `OMNI_HOME` if
your omni checkout is not a sibling of this repository.

Note one real gap, recorded in [`spec/README.md`](../spec/README.md):
unlike ten of the other ports, this one has **no completeness guard**. It
hand-writes a test per section rather than deriving them from a table, so
a section added to the corpus would silently not run *here* — in the very
port the others are translated from. Verified by mutation: a bogus
section added to `station.json` passes this suite and fails ten others.

The integration suites run against a REAL generated SDK (generated by
sdkgen with the station feature) and the test API servers in
[`test/api/`](../test/api/). Without a generated checkout
(`STATION_TEST_SDKS`, default `/home/user/voxgig-sdk`) they skip rather
than fail.
