# station 0.3.0

Released from `main` in one run of `release.yml`:

- `@voxgig/station` on npm;
- `@voxgig/station-js` on npm;
- the Go module, at `go/v0.3.0`.

Every other port also declares 0.3.0, and is consumed from this
repository.

0.3.0 carries the plan's W1, W2a and W2b. The plan had put W2b in a
later 0.3.x, but it landed first.


## What a 0.2.0 user will see change

- **Feature options are checked as the SDK checks them**
  ([#60]). A named instance gets its declared options. A feature that
  is not `strict` no longer reports a misspelled option, because the
  SDK does not.
- **Refusal messages cite the design's section as `(§N)`** ([#48]).
  The error codes are unchanged, so match on `code` rather than on a
  message's text.
- **A failed operation emits one `op` event** ([#36]), where 0.2.0
  emitted two or three.
- **An `http` event reports the path exactly as sent** ([#51]).
- **An `http` event reports the host as `URL.host` reads it** ([#56],
  [#55]). It is in lower case and keeps an IPv6 address's brackets. A
  default port is dropped, as are an empty port and a port's leading
  zeros.
- **The hosts policy reads the hostname as `URL.hostname` does**
  ([#54]), and compares its keys in lower case. rust and swift used to
  read a URL's user name as its host, so `https://api.test:x@evil.test/x`
  passed an allowlist naming `api.test` ([#56]). It no longer does.
- **Policy mode `block` raises `station_blocked`**, a new error code
  ([#64]), where typescript raised `station_host_allow`. Every port now
  gates the policy mode. Before, in fourteen ports a live request under
  `block`, `record`, `replay` or `mock` reached the transport. The last
  three now fail with `station_no_proxy`, because only the proxy can
  serve them.
- **`station.json` is read strictly**, and each of these refusals is
  `station_config_invalid`:
  - an unpaired surrogate escape ([#61]);
  - a text that is not JSON, which java used to read anyway;
  - bytes that are not UTF-8, which several ports used to replace or
    read as Latin-1;
  - a leading byte order mark, which csharp, dart and newer Swift
    Foundations used to strip.

  The proxy daemon reads its own copy of the file the same way.
- **A password in a block's `base`, or in a URL that does not parse,
  is refused** ([#57]).
- **The C port resolves secrets through sekreto's C port** ([#58]). It
  refuses a provider kind it used to warn about.


## Fixes

- **No secret in what gets printed.**
  - The SDK's options hold no Station and no caller key ([#37]).
  - An `http` event keeps no userinfo from a URL it reports whole
    ([#53]).
  - The scrub reaches the chain of errors behind a transport error
    ([#29]).
- **`connect()` and `adopt()` take sdkgen's list form of
  `options.feature`.** They keep the caller's order, and place station
  where it is pinned: right after `test`, or else first.
- **A declared feature order reaches the SDK.** Before, a `before` or
  `after` constraint that disagreed with the alphabet was dropped.
- **Station's place in the feature order when `test` is absent**
  ([#63]). `connect()` with `retry` active used to fail with
  `station_wrap_order`.
