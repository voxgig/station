# station — JavaScript

The JavaScript port of [station](../README.md): one control surface for
outbound integrations.

```sh
npm test                      # conformance + integration suites
```

A direct port of the TypeScript, minus the types. Secrets are brokered
through `@voxgig/sekreto-js`.

`Station.js` requires `adapter.js` lazily — at the single point
`construct()` needs the carried adapter. CommonJS resolves the cycle
that way round; the other way, `adapter` would see a half-built module.

## Layout

| | |
|---|---|
| `src/Station.js` | the core: open/connect/adopt/options, registry, transport middleware |
| `src/adapter.js` | `featureBinding` (the one binding entry) + the carried adapter |
| `src/descriptor.js` | descriptor v1 normalizer + canonical serializer |
| `src/secrets.js` | the sekreto-backed broker + the placeholder |
| `src/profile.js` | `station.json` lookup and profile resolution |
| `src/events.js` | the bounded event ring + tap |
| `src/error.js` | the error-code catalog |
| `test/conform.test.js` | the conformance suite |
| `test/quickstart.test.js` | the §11 walkthroughs, against a live test API |
| `test/pets.test.js` | the awkward cases, against the gnarly-pets test API |

## Testing

The conformance suite runs [`spec/station.json`](../spec/station.json) —
the same file every port runs — through the JavaScript
[voxgig/omni](https://github.com/voxgig/omni) runner. Set `OMNI_HOME` if
your omni checkout is not a sibling of this repository.

The integration suites run against a REAL generated SDK (the js target
of gnarly-pets, generated by sdkgen with the station feature) and the
test API servers in [`test/api/`](../test/api/). Without a generated
checkout (`STATION_TEST_SDKS`, default `/home/user/voxgig-sdk`) they
skip rather than fail.
